## R2 and Workers

Fetched [R2 Workers API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/), [presigned URLs](https://developers.cloudflare.com/r2/api/s3/presigned-urls/), [Workers limits](https://developers.cloudflare.com/workers/platform/limits/), [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/), and [R2 pricing](https://developers.cloudflare.com/r2/pricing/). Streamed R2 APIs and conditional/checksummed PUT are implemented. Streaming does not remove the 100 MB Free/Pro ingress cap or 128 MB isolate memory limit. Standard R2 S3 PUT staging avoids proxying a whole large request through Worker ingress; verify triggers bounded chunk ingest. Single-object envelope intentionally capped at 256 MiB, while benchmark generator permits only 101–128 MiB. No S3 key creation or live signature enforcement claim. Worker build succeeds locally but is not a runtime/account entitlement proof. No Sandbox dependency or deprecated 0.x sample is used; ordinary Workers never execute Linux subprocesses.
