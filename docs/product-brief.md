# Core product brief

Latest authorization: finish the core forge, keep `vasanthsreeram/cf-native-forge` private, deploy/test dedicated resources, and migrate a substantial public owned GitHub project without changing the source. Earlier preparation-only restrictions and planned native CI are superseded. The original requirement register is retained in [the planning archive](archive/product-brief-planning.md).

The product provides WorkOS identity, private repository creation, searchable owned/shared lists and optional public discovery, file/README/history browsing, explicit visibility, repository grants and verified-email invitation links, native Git credentials, GitHub URL imports, independent task forks, immutable proposals/diffs, human review, and controlled stale-head-safe publication. R2 LFS uses repo manifests and tenant-scoped deterministic CDC chunks.

Native CI/check runners, Agents SDK, Sandbox, Containers, hosted model/edit/test features, and executing/building imported code are **excluded**, not future MVP dependencies. Optional externally supplied status is informational and cannot authorize merge. The existing shell benchmarks and application tests are developer tooling only.

Actual evaluation remains private: public capability tests use disposable local synthetic fixtures. No migrated project or demo was published. Competition submission, license/publication decisions, custom domains, subscriptions and production application changes are outside this work.

The distinction between implemented, locally exercised, directly tested on a provider, and exercised through a real deployed user session is essential. [The current status matrix](implementation.md) identifies the exact remaining user-bound setup. The app is not represented as fully complete while WorkOS login and live R2 LFS remain unverified.
